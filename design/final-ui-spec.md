> 设计负责人：Claude Code

> 可访问性修订会话：`778780ec-a72b-429e-b83c-870929282734`  
> 目标平台：macOS、Windows  
> 目标画布：`380 × 560 px`

## 1. 设计定位

在已批准的紧凑面板布局上，剥离视觉参考中的侧栏、统计卡、标签墙、吉祥物、头像等大型任务管理器元素，仅保留“蓝白轻玻璃、大圆角、柔和阴影、精致线性图标”的视觉语言。

最终产品是一个克制、精致、纯键盘可控的桌面待办弹层：女性用户会觉得细腻好看，但不甜腻、不幼稚、不堆叠装饰。

- `VARIANCE = 3`：只保留蓝、绿、琥珀、红四种语义色。
- `MOTION = 2`：只有状态过渡，无弹跳、插画动画或营销动效。
- `DENSITY = 6`：中高信息密度，维持 8–12 px 的呼吸间距。

## 4. 交互与键盘流程

### 新增

- 面板打开后立即聚焦新增输入框
- `Enter` 提交、清空输入内容并保留输入焦点
- 新项目插入“今天”顶部，短暂高亮 `100 ms`
- IME 组合状态中 `Enter` 只确认候选，不提交任务

### 搜索

- `⌘/Ctrl+F` 进入搜索态
- 新增条原位变形为搜索框，不跳转页面
- 左侧加号替换为放大镜
- 占位文案：“搜索待办…”
- `80 ms` 防抖实时过滤
- `↑/↓` 移动搜索结果
- `Enter` 定位/展开结果，不新增任务

### 列表导航

- `↑/↓` 移动当前选中行
- 选中行显示背景色和左侧强调条
- 自动执行 `scrollIntoView({ block: "nearest" })`
- 输入法候选框打开时，方向键优先交给 IME

### 完成与撤销

- 选中任务后按 `Space` 完成
- 完成时：圆圈填色、勾选动画、删除线、透明度降低至 60%
- 完成项目归入折叠区
- 已完成项目再次按 `Space` 撤销，使用 `200 ms` 高度过渡返回原分组

### 提醒编辑

- 选中行按 `Enter` 或 `E` 展开行内提醒面板
- 提供“一次性”“重复”两个页签
- `Tab` 在字段间移动
- `Enter` 保存并收起
- `Esc` 取消并恢复原值

### 完成记录

- 默认收起
- 在折叠入口按 `Enter` 或 `Space` 展开
- 展开后仍支持 `↑/↓` 和 `Space` 撤销

### 设置与主题

- 点击齿轮或按 `⌘/Ctrl+,` 打开轻量浮层
- 主题选项：跟随系统 / 浅色 / 深色
- 左右方向键切换
- `Enter` 即时生效，无保存按钮

### Esc 分级

1. 搜索态：退出搜索并恢复普通新增态
2. 提醒或设置子层：关闭子层并恢复任务行选中
3. 普通态：关闭整个弹层，并把焦点还给打开前的窗口/控件

### 外部点击与草稿

- 点击面板外部关闭弹层
- 未提交草稿保存在内存
- 下次打开时恢复草稿，并把光标放在末尾
- 搜索态不跨关闭保留

### 中文 IME

- 监听 `compositionstart` / `compositionend`
- 同时检查 `event.isComposing`
- Windows 老旧输入法使用 `keyCode === 229` 兜底
- 组合期间 `Enter` / `Esc` / `↑` / `↓` 优先交给输入法

## 5. 图标体系

统一几何骨架：单条连续缎带形成横向无限环，并自然承托单一对勾。
无限环表达“长久陪伴与持续记得”，对勾表达“随手完成”；菜单栏与
托盘尺寸降级为同一骨架的单色线性版本。

- 缎带描边：`1.5 px`（小尺寸按像素网格微调）
- 对勾落在右侧环内，避免与交叉点粘连
- 四种状态只改变右上角状态点，不改变主体形状

### 桌面应用图标

- 源尺寸：`1024 × 1024 px`
- 暮色靛青背景，边缘含克制的薰衣草与浅绯柔光
- 柔和缎面质感与浅层高光，不使用玻璃拟态或霓虹
- 中央使用暖象牙白无限缎带与对勾

### macOS 菜单栏

- `18 pt` Template Image
- 导出 `36 px`、`54 px`
- 纯黑单色线性图标，由系统随明暗主题自动反相
- 描边 `1.5 px`
- 无渐变、无阴影

### Windows 托盘

- 导出 `16 / 20 / 24 px`
- 浅色任务栏：`#3C3F4A`
- 深色任务栏：`#E8EAF0`
- 根据任务栏主题手动换图
- 小尺寸无阴影、无渐变

### 状态

- `normal`：无状态点
- `unfinished`：右上角状态点，浅色界面 `#3E7BFA`，暗色界面 `#6C93FF`
- `overdue`：浅色 `#E5484D`，暗色 `#FF6B6F`；`24 px` 以上可含感叹号，`16 px` 不放
- `reminder-triggered`：浅色 `#B8790A`，暗色 `#F2B75B`；Windows 可增加 1–2 圈微光，macOS 菜单栏降级为静态点

## 6. 图像生成提示词

### Light Panel

> 生成一张 380×560 像素的桌面待办事项弹出面板 UI 设计图，浅色主题。画布圆角 20px，背景为浅蓝白色 #F6F9FF 半透明轻玻璃质感（20px 模糊）。构图自上而下：顶部 header 含蓝色圆形对勾徽标、“今天”标题 18px 黑色文字、日期与待办计数 12px 灰色副标题，右侧两个线性图标按钮（搜索放大镜、设置齿轮）；其下一条白色胶囊形快速添加输入框，左侧蓝色圆形加号，占位文字“添加一项待办…（Enter 保存）”，右侧日历线性图标；主体为“今天”与“稍后”两个分组的任务列表，每行含空心圆形勾选框、14px 深色任务文字、右侧提醒时间或重复图标，其中一行显示为蓝色左侧强调条与浅蓝背景的键盘选中态；列表底部是一行“已完成 12 项”的折叠入口；最底部固定快捷键提示条，展示“⌘/Ctrl+F 查找、↑↓ 选择、Space 完成、Esc 关闭”。使用柔和阴影、大圆角、精致线性图标和系统无衬线字体。状态视觉色限定为蓝 #3E7BFA、绿 #1E9C60、琥珀 #B8790A、红 #E5484D。整体必须克制、清爽、高级、非甜腻卡通。禁止吉祥物、头像、侧边栏、统计卡、标签墙、广告位、优先级、项目和日历页面。

### Dark Panel

> 生成与 Light Panel 完全相同构图和内容的 380×560 深色主题版本。背景为深蓝紫黑 #14151E；卡片与输入框表面为 #1C2030 半透明轻玻璃，而不是简单反色；主强调色 #6C93FF、完成色 #3FD98A、提醒色 #F2B75B、重复色 #A78BFA、逾期色 #FF6B6F；主文字 #EDEFF7，次文字 #A2A9C4。卡片边缘使用 1px 半透明白色内高光线分层，阴影更深更柔。圆角、间距、字号、图标位置必须与浅色版完全一致。禁止纯黑背景、霓虹赛博风、过强发光、吉祥物、头像、侧栏、统计卡、标签墙和广告位。

### Icon Board

> 生成一张专业图标系统设计板，横向排列三组。第一组：1024×1024 桌面应用图标，蓝白渐变圆角方形背景板、轻玻璃高光、中央 accent 蓝色实心对勾清单。第二组：macOS 菜单栏 18pt 单色线性模板图，展示 normal、unfinished、overdue、reminder-triggered 四种状态。第三组：Windows 托盘图标，展示 16/20/24px 三档尺寸、浅色任务栏深灰版本和深色任务栏浅灰版本，并展示同样四种状态。所有图标共享同一圆角矩形清单加对勾几何骨架，状态仅改变右上角圆点。未完成使用蓝色，逾期使用红色，提醒使用琥珀色。菜单栏与托盘小图标禁止渐变、阴影、3D、复杂细节和主体形状变化；图标必须在 16px 下仍然清楚锐利。

1. macOS 菜单栏 Template Image 在浅色/深色下的自动反相与 18pt 清晰度。
2. Windows 10/11 托盘图标随任务栏主题换图时是否闪烁。
3. Esc 关闭后跨应用焦点是否能稳定回到原窗口。

5. macOS 毛玻璃与 Windows Mica/Acrylic 下的模糊强度和性能。
6. 中文候选窗是否遮挡输入框与任务列表。
