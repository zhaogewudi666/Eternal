# Eternal v0.2.8

本地优先、键盘优先的轻量待办面板：全局快捷键唤出，用完即隐，Windows 托盘 / macOS 菜单栏常驻。

## 本版亮点

- **Windows 自动更新**：设置 →「软件更新」可检查新版本；发现新版后点「立即更新」自动下载、静默安装、自动重启，全程无需手动操作
- **主面板直接编辑标题**：选中任务后按 `⌘E`（macOS）或 `Ctrl+E`（Windows），任务标题回填到顶部输入框编辑，`Enter` 保存、`Esc` 取消；列表保持整洁
- **鼠标也能编辑**：展开任务行后右侧 ✏️ 按钮进入编辑
- **列表保持简洁**：默认单行，点击展开全文，再次点击收起
- **长文本完整显示**：输入超长任务时输入框自动增高为多行

## 校验与签名

安装前请用本 Release 附带的 `SHA256SUMS` 校验完整性：

```bash
shasum -a 256 -c SHA256SUMS
```

- **Windows**：未代码签名。若 SmartScreen 提示拦截，核对哈希后可「更多信息」→「仍要运行」
- **macOS**：仅 ad-hoc 签名，无 Developer ID，也未公证。首次打开若被拦截，可右键应用 →「打开」
