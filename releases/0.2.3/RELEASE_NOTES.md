# Eternal v0.2.3

本地优先、键盘优先的轻量待办面板：全局快捷键唤出，用完即隐，Windows 托盘 / macOS 菜单栏常驻。

## 本版亮点

- **连贯键盘流**：`/` 搜索，`↑` / `↓` 在捕获与列表间移动（不环绕），`Space` 完成或恢复，可打印字符直接回到输入
- **提醒与安全删除**：对选中任务设置提醒；`Backspace` / `Delete` 需确认后再删
- **分区列表**：未完成在上，已完成在下，同屏可导航
- **中性原生外观**：浅色 / 深色 / 跟随系统；无边框圆角面板
- **可配置全局快捷键**：默认 `⌘⇧Space` / `Ctrl+Shift+Space`，设置中改绑
- **钉板快捷键**：`⌘⇧P` / `Ctrl+Shift+P` 在主页面切换钉板，不占用全局呼出快捷键
- **可选开机自启**：默认关闭；开启后静默驻留托盘/菜单栏，不抢焦点
- **位置记忆与后台常驻**：记住上次窗口位置；收起后从托盘或菜单栏再次打开

## 校验与签名

安装前请用本 Release 附带的 `SHA256SUMS` 校验完整性：

```bash
shasum -a 256 -c SHA256SUMS
```

- **Windows**：未代码签名。若 SmartScreen 提示拦截，核对哈希后可「更多信息」→「仍要运行」
- **macOS**：仅 ad-hoc 签名，无 Developer ID，也未公证。首次打开若被拦截，可右键应用 →「打开」，或在「系统设置 → 隐私与安全性」中选择仍要打开

## 请你本机确认

实体登录后的开机自启，以及 SmartScreen / Gatekeeper 的点选放行，请在真实设备上自行冒烟验证。

## main 分支后续功能更新

以下功能已合入 GitHub `main`，本次重新构建的 0.2.3 安装包已同步到本 Release：

- **主页面钉板**：默认关闭，只抑制失焦自动收起；主窗口仍保持置顶。
- **滚动修复**：任务列表改为单一滚动容器，长列表在 macOS / Windows 上均可继续滚动。
- **初始选中修复**：打开面板时不再错误显示选中框；使用方向键后只显示一个与键盘状态一致的选中项。
- **桌面组件**：本版暂不提供；已移除未完成的 WebView 组件入口，避免与原生桌面组件混淆。
- **升级防丢数据**：升级前复制任务文件到 `backups/`，保留原文件；快照失败、快照冲突或更高数据格式会进入写保护，避免空列表覆盖旧数据。

升级时请先退出旧版本，再直接覆盖安装新版；不要卸载后删除应用数据目录。当前仍需手动安装，没有自动更新器。
