# Eternal v0.2.10

本地优先、键盘优先的轻量待办面板：全局快捷键唤出，用完即隐，Windows 托盘 / macOS 菜单栏常驻。

## 本版修复

- **`⌘E` / `Ctrl+E` 编辑快捷键修复**：之前必须先用键盘选中任务才生效；现在直接按 `⌘E` / `Ctrl+E` 即可编辑当前选中任务，未选中时自动编辑第一条待办，焦点在输入框也不受影响
- **编辑时不显示旧标题**：进入编辑后，被编辑的任务会从列表中暂时隐藏，保存或取消后带着新标题回到原位，面板不再同时出现「上面编辑、下面旧标题」的重复显示

## 校验与签名

```bash
shasum -a 256 -c SHA256SUMS
```

- **Windows**：未代码签名。若 SmartScreen 提示拦截，核对哈希后可「更多信息」→「仍要运行」
- **macOS**：仅 ad-hoc 签名。首次打开被拦截时右键应用 →「打开」
