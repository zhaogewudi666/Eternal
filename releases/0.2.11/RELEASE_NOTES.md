# Eternal v0.2.11

本地优先、键盘优先的轻量待办面板：全局快捷键唤出，用完即隐，Windows 托盘 / macOS 菜单栏常驻。

## 本版改进

- **快捷键按平台区分**：macOS 用 `⌘E` 编辑任务，Windows 用 `Ctrl+E` 编辑任务
- **编辑框最多三行**：输入或编辑长标题时输入框随内容增高，最多显示三行；再长会在框内滚动，不再撑变形整体面板；开始编辑已有多行标题的任务时，输入框会立即展开到合适高度

## 校验与签名

```bash
shasum -a 256 -c SHA256SUMS
```

- **Windows**：未代码签名。若 SmartScreen 提示拦截，核对哈希后可「更多信息」→「仍要运行」
- **macOS**：仅 ad-hoc 签名。首次打开被拦截时右键应用 →「打开」
